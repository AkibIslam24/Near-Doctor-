# 🏥 NearDoc (MVP Demo)

NearDoc is a simple web-based healthcare application that allows users to quickly find nearby doctors, request emergency services, and book appointments. This project is built as a **Minimum Viable Product (MVP)** to demonstrate the core idea and user flow of an on-demand doctor service platform.

---

## 🚀 Features

### 🔴 Emergency Service
- View available doctors for emergency situations
- See doctor details (name, specialty, distance, fee)
- Select a doctor and confirm emergency call
- Consent validation before confirming
- Payment method selection (Cash, bKash, Nagad, Card)

---

### 📅 Appointment Booking
- Browse doctors for scheduled appointments
- View doctor profiles with fees and ratings
- Select a doctor and proceed to schedule

---

### 🕒 Schedule Selection
- Choose date (next 7 days)
- Select available time slots (Morning / Afternoon / Evening)
- Handle unavailable slots
- Add reason for visit (optional)
- Option to share patient location
- Confirm appointment with booking ID

---

## 🧩 Tech Stack

- **Frontend:** HTML, CSS, Bootstrap
- **Logic:** JavaScript
- **Backend (Basic):** PHP
- **Environment:** XAMPP (Apache Localhost)
